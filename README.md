# From chatbot to agent in Radiology AI

A **60-minute**, presenter-led hands-on session for the Trainee Editorial Board of *Radiology: Artificial Intelligence*.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/eduardofarina/hands-on-agentes-jpr2026/blob/handson_teb/hands_on_agentes_jpr2026.ipynb)

## Session concept

The notebook goes beyond obtaining answers from an LLM. It shows how to evaluate the complete system:

- model, goal, instructions, tools, and context;
- the action–observation loop;
- stop conditions and cost limits;
- traceability of tool calls and retrieved evidence;
- multimodal evaluation, failure modes, and human oversight;
- editorial questions for manuscripts that use the term *agentic*.

The central example is an editorial triage agent grounded in an educational synthesis of the **CLAIM 2024 Update**. Other examples use a synthetic worklist, PubMed, and public images.

## Live-session format

- Total duration: **60 minutes**.
- Operation: **one presenter runs every cell on screen**.
- Participation: the audience chooses questions, review priorities, and attacks on the agent.
- Contingency: the PubMed search is a bonus and can be skipped without affecting the rest.

## Google AI Studio and billing

The session uses one presenter-owned `GOOGLE_API_KEY` linked to prepaid credits in Google AI Studio.

1. Create or select a project dedicated to the session.
2. Confirm the balance, billing, and *project spend cap*.
3. In Colab, save the key in **Secrets** as `GOOGLE_API_KEY`.
4. Enable **Notebook access**.
5. Never paste the key into a cell or share it with the audience.

The notebook pins tested library versions and limits tokens and tool calls. Even so, monitor usage in the AI Studio dashboard.
